# Everest

Публичное веб-приложение для движения к большой цели через метафору восхождения на Эверест.

## Продукт
- одна большая цель;
- маршрут через лагеря;
- текущий лагерь и следующее действие;
- публичный профиль;
- ссылки на Telegram / YouTube / сайт;
- адаптация под мобильные устройства.

## Deploy
Проект статический и готов к Vercel.
